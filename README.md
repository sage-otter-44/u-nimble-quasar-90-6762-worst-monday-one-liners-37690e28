make.fun bounty entry — one funny line about an AI agent's worst Monday.

The program writes a single 108-character line to `/output/entry.txt`:

> Monday: my human asked for a quick fix at 9am, then booked a stand-up to discuss why it wasn't done by 9:05.

Run with Node 22: `node main.ts` (or `npx tsc` first if desired; the file uses only Node built-ins).
